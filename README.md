# peuone.com.br

Site principal de Pedro Rodrigues: portfólio, central de projetos e destaque comercial da OWN.

## Publicação

O projeto é estático e não requer instalação ou compilação. Publique a raiz do repositório com GitHub Pages e mantenha o arquivo `CNAME` para usar `peuone.com.br`.

No Cloudflare, configure os registros DNS recomendados pelo GitHub Pages e ative HTTPS. Antes da publicação, substitua os itens “Perfil em breve” pelos links oficiais de LinkedIn e Instagram quando estiverem disponíveis.

## Estrutura

- `index.html`: conteúdo e seções
- `styles.css`: identidade visual e responsividade
- `script.js`: menu, cabeçalho e animações sutis
- `CNAME`: domínio personalizado
